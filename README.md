# ももんがの夜の森

月夜の森を進む、ももんが主人公の2Dドット絵アクションゲーム（HTML5 Canvas / 依存ライブラリなし）。

## 遊び方
`index.html` をブラウザで開くだけ。

| 操作 | キー |
|---|---|
| 左右移動 | ← → (A / D) |
| ジャンプ | ↑ (W / Space) |
| グライド | 空中で Z (X / Shift) を押し続ける（ゲージあり、着地で回復） |
| ポーズ | P / Esc |

スマホではタッチボタンが表示されます。

## ルール
- コイン＝スコア、おたから（青い玉）＝ハート回復／ムテキ
- 岩・コウモリに当たるとハート減少、湖に落ちても減少。コウモリは上から踏むと倒せる
- 進むほど足場の間隔が広がり、岩とコウモリが増える

# 転生林檎ダイブ（`tensei-ringo/`）

ピノキオピー「転生林檎」のイメージで作った縦スクロールのダイブゲーム（オリジナル、歌詞等は不使用）。
`tensei-ringo/index.html` をブラウザで開くだけ。

- 操作: ← → / A D、またはタッチ・ドラッグで林檎を左右に動かす
- 刃を避け、金の種で連続ボーナス、♥で回復
- 刃に当たると「転生」して別の林檎（赤→青→金→黒→白）に。ライフ0でゲームオーバー

# 転生林檎 ―めぐる果樹園―（`tensei-rpg/`）

アンダーテール風のドット絵RPG。`tensei-rpg/index.html` をブラウザで開くだけ（スマホはタッチパッド表示）。
ピノキオピー「転生林檎」の雰囲気にインスパイアされたオリジナルストーリー（歌詞は不使用）。

- 操作: 十字キー=移動 / Z=決定 / X=キャンセル（戦闘中は長押しで低速移動）/ C=メニュー
- 探索 → 住人との遭遇 → ターン制バトル（たたかう / こうどう / アイテム / みのがす + 弾よけ）
- 倒れると「転生」して林檎の色が変わり、部屋の入口から再開
- 全員を傷つけずに進むと…？ エンディングは3種（TRUE / STAY / NEUTRAL）
- はじまりの苗でHP回復＋セーブ
