# ももんがの夜の森

月夜の森を進む、ももんが主人公の2Dドット絵アクションゲーム（HTML5 Canvas / 依存ライブラリなし）。

## 遊び方
`index.html` をブラウザで開くだけ。

| 操作 | キー |
|---|---|
| 左右移動 | ← → (A / D) |
| ジャンプ | ↑ (W / Space) |
| グライド | 空中で Z (X / Shift) を押し続ける（ゲージあり、着地で回復） |
| ポーズ | P / Esc |

スマホではタッチボタンが表示されます。

## ルール
- コイン＝スコア、おたから（青い玉）＝ハート回復／ムテキ
- 岩・コウモリに当たるとハート減少、湖に落ちても減少。コウモリは上から踏むと倒せる
- 進むほど足場の間隔が広がり、岩とコウモリが増える

# ツボ登り（`tsubo/index.html`）

ツボに入ったおじさんがハンマー1本で山を登る、Getting Over It 風の物理アクション。依存なし・`tsubo/index.html` をブラウザで開くだけ。

- **マウス（タッチ）**: ハンマーをその方向へ振る。岩に引っかけて体を引き上げる／押し出す
- **R**: 最初から
- 高さ64mの山頂が目標。落ちても戻されない（落下回数とタイムを記録）
