# ももんがの夜の森

月夜の森を進む、ももんが主人公の2Dドット絵アクションゲーム（HTML5 Canvas / 依存ライブラリなし）。

## 遊び方
`index.html` をブラウザで開くだけ。

| 操作 | キー |
|---|---|
| 左右移動 | ← → (A / D) |
| ジャンプ | ↑ (W / Space) |
| グライド | 空中で Z (X / Shift) を押し続ける（ゲージあり、着地で回復） |
| ポーズ | P / Esc |

スマホではタッチボタンが表示されます。

## ルール
- コイン＝スコア、おたから（青い玉）＝ハート回復／ムテキ
- 岩・コウモリに当たるとハート減少、湖に落ちても減少。コウモリは上から踏むと倒せる
- 進むほど足場の間隔が広がり、岩とコウモリが増える

## リズム戦闘モード
タイトル画面で `B`（スマホは画面下端タップ）。アンテ風の弾幕回避戦闘で、曲の音符1つ＝弾1つ。音が鳴る瞬間に弾が届きます。
操作: ← → ↑ ↓ / WASD でももんが移動（赤い点が当たり判定）、X / Shift でゆっくり、Esc でタイトル。
同梱曲はオリジナルの仮曲です。曲データ(JSON)を画面にドラッグ＆ドロップすると差し替えられます:
`{"title":"曲名","bpm":150,"lead":[["A4",0.5],["R",1],...],"bass":[["A2",2],...],"loops":1}`（拍数 1 = 四分音符、"R" = 休符）
