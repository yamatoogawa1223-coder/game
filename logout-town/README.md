# ログアウトできない街

スマホと仕事に追われて眠れなくなった人が迷い込む「夜の来ない街」を、上へ上へとのぼっていく弾幕×対話RPG（HTML5 Canvas / 依存なし）。

## 遊び方
`logout-town/index.html` をブラウザで開くだけ。スマホではタッチボタンが表示されます。

| 操作 | キー |
|---|---|
| 移動・選択 | 矢印 / WASD |
| 決定 | Z / Enter / Space |
| 戻る・ゆっくり移動 | X / Shift |

## ルール
- コマンドは FIGHT / ACT / ITEM / MERCY。弾幕の中でハートを動かして避ける。
- **やさしいルート**: ACTで相手の話を聞き、MERCYで見逃す。各階でHP全回復、街は少しずつ静かな夜になる。
- **効率ルート**: 1体でもFIGHTで倒すと、街は静かで便利になる代わりにHPの上限が減り、回復しなくなる。最後は本当にログアウトできなくなる。
- 真のエンディングは「誰も倒さずに」最上階のオートさんを眠らせること。
