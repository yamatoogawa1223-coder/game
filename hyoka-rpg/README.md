# 評価社会 RPG

「評価社会」のドット絵RPG版（HTML5 Canvas / 依存なし）。`hyoka-rpg/index.html` をブラウザで開くだけ。
シナリオ・イベントは `hyoka-shakai` と共通（`events.js`）。

| 操作 | キー |
|---|---|
| 歩く | 矢印 / WASD |
| 話す・調べる・決める | Z / Enter / Space |

- 街を歩いて「！」のついた人や端末に話しかけると、その日の評価イベントが起きる。
- 用事が済んだら自宅のドア（上向きで Z）で眠る。残した用事は1件につき -6。7日目・14日目に家賃審査。
- 頭上の監視カメラの視野は赤く光る。スコアが上がるほど画面は色を失い、街の人の顔も消えていく。
- 隠しパラメータ「あなたらしさ」は最後の画面で公開される。エンディングは7種。
