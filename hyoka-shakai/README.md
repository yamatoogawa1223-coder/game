# 評価社会

毎日の行動が全部「スコア」になる社会で14日間生き延びる、選択型テキストシミュレーション（HTML / 依存なし）。
`hyoka-shakai/index.html` をブラウザで開くだけ。

- 愛想・SNS投稿・通報・交友関係などの選択でスコアが上下する。7日目と14日目の家賃審査でランクCだと退去。
- 画面には出ない隠しパラメータ「あなたらしさ」が、選択のたびに削れていく。削れるほど画面は色を失い、正直な選択肢は黒塗りで選べなくなり、「★推奨」の誘導が強まる。
- 他人を踏み台にした選択は後の日に結果が返ってくる（カワイさんの部屋、タカギ、ミオ）。
- エンディングは6種（模範市民 / きれいな手 / まだ、あなた / 平均的な誰か / 評価圏外 ×2 / 圏外へ）。終了時に、隠されていた「あなたらしさ」がスコアと並べて公開される。
